# Security Policy

## Supported Versions

Currently, the `main` branch (v1.0.0 and above) is actively supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Dhatree AI, please do not disclose it publicly. Instead, please send an e-mail to the maintainer detailing the vulnerability.

We will review the submission and respond within 48 hours. If the vulnerability is accepted, we will coordinate a fix and a public disclosure.

Please include:
- A description of the vulnerability.
- Steps to reproduce it.
- Possible impact.

Thank you for helping keep Dhatree AI secure!
