# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-07-25

### Added
- Complete Modular Monolith Django Architecture.
- Farm and Crop Management APIs.
- AI-Powered Crop Recommendation Engine (Random Forest).
- AI-Powered Fertilizer Recommendation Engine (Neural Network).
- AI-Powered Plant Disease Detection (ResNet50).
- Gemini-powered AI Agricultural Assistant.
- React/TypeScript/Vite Frontend with TailwindCSS.
- Unified Recommendation History and JWT Authentication.
- Comprehensive Test Suites (Pytest & Vitest).
